🛒 Shopping Program

A simple command-line shopping program built with Python.

The program allows the user to enter food items and their prices, stores them in lists, displays the shopping cart, and calculates the total price.

This project was created to practice Python lists, loops, user input, conditions, and basic calculations.

🚀 Features
🛍️ Add food items to the shopping cart
💰 Enter the price of each item
📋 Display all items in the cart
🧮 Calculate the total price
❌ Exit the program by entering q
🛠️ Technologies
Python 3
Lists
while loops
for loops
if / else conditions
User input
Basic arithmetic operations
▶️ How to Run

Make sure Python 3 is installed on your computer.

Clone the repository:

git clone https://github.com/YOUR-USERNAME/shopping-program.git

Go to the project folder:

cd shopping-program

Run the program:

python shopping_program.py
